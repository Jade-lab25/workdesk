❓ 使用说明

✕

💡 灵感库 — 怎么用？

灵感库用来快速记录碎片化的想法、灵感、待办、读书摘记等任何你不想丢失的念头。

  • 在输入框里写任何内容，点「记录」或按 Ctrl+Enter 保存
  • 记录前用 方向 切换选「工作」或「个人成长」，生成日报/周报时会自动把两类灵感分开展示（旧灵感显示「未分类」）
  • 每条灵感都会显示 添加时间
  • 用 #标签 给灵感分类，比如 #产品想法 #读书 #待研究
  • 点方向筛选或标签筛选按钮，只看某一类灵感
  • 每条灵感右下角有三个操作：
    • 转日志：把灵感转成一条工作日志草稿，跳转到日志 Tab 继续编辑
    • 转素材：保存为「待总结素材」，生成总结时会被自动纳入
    • 删除：删掉这条灵感

📋 工作日志 — 怎么用？

工作日志是结构化记录，方便后续 AI 自动生成周报/日报。每个条目四个字段：

  • 事项：做了什么（必填）
  • 结果：产出/效果如何
  • 数据：量化成果的数字（有就填，生成的报告更有说服力）
  • 问题：遇到的困难或风险（没有就不填）

顶部左右箭头可以切换日期，补记之前的工作。

✨ 总结生成 — 怎么用？

  1. 选模板：6 种行业模板，选最贴近你场景的
  2. 选范围：
    • 日报：当天的所有日志 + 灵感 + 素材
    • 周报：本周一到周日的所有内容
    • 自定义：手动选起止日期
  3. 下方会显示「将纳入 X 条素材」，确认范围对了就点 生成总结
  4. 生成后可以 复制、存档（存到报告库）、重新生成
  5. 历史报告都在下方，可以点开回看

⚙️ AI 设置

第一次使用需要配置 AI 模型：

  • 选择你的服务商（DeepSeek / 火山引擎 / OpenAI 等）
  • 填入 API Key（只保存在你的浏览器里，不上传任何服务器）
  • 模型名可以从下拉候选中选，也可以手动输入
  • 点 测试连接 确认配置正确
  • 点 保存配置 生效

🤖 AI 连不上？按顺序排查

本平台默认就能浏览器直连主流大模型（已实测 DeepSeek、火山方舟、智谱、通义、OpenAI 均可直连，无需代理）。 点「测试连接」如果报错，绝大多数是配置问题，请按顺序检查：

  1. API Key 对不对：有没有多空格、复制全、没过期。Key 错误时服务商通常返回 401。
  2. 服务商选对了吗：Key 是哪家的，服务商就要选哪家。
  3. 模型名对不对：用下拉里的候选名，或服务商官网的准确模型名（如 DeepSeek 是 deepseek-chat）。模型名错会返回 400/404。
  4. 火山引擎：需要用「Agent Plan 专属 API Key」并开通套餐，普通方舟 Key 不一定能用。
  5. 改完记得点「保存配置」再「测试连接」。

极少数情况：你所在的网络（公司网、校园网、某些地区）屏蔽了对该服务商的直连。这时才需要在 ⚙️ 设置 → 网络代理 里填一个自建的 CORS 中转地址（可选，非必需）：

  1. 在 Cloudflare（免费）建一个 Worker
  2. 把项目里 cors-proxy-worker.js 内容粘进去 → Deploy
  3. 复制得到的 https://xxx.workers.dev 填进「网络代理」→ 保存

⚠️ 代理能看到你的 API Key，请务必用自己部署的、不要用他人公开代理。

☁️ 多端同步

  • PC 和手机用同一个链接打开、同一个账号登录，数据自动同步
  • 右上角「已同步资料库」表示一切正常
  • 「未登录」状态下也可以用，数据存在本机，登录后自动上传
  • 每 60 秒自动同步一次，也可以随时手动刷新

💡 最佳实践

  • 想到什么先记到灵感库，别让想法跑掉
  • 每天下班前花 5 分钟，把灵感库里相关的转成工作日志
  • 每周五下午一键生成周报，微调后直接发出去
  • 生成的报告不满意？点「重新生成」，或者手动编辑后再存档
